# UTA-024 Engineering Design Project-II — Buggy Lab

This repository contains the **XBee communication, ground-station, sequencing, and stage-wise implementation code** developed for **UTA-024 Engineering Design Project-II (Buggy Lab)**.

The project provides hands-on implementation of an integrated Arduino-based buggy/robotic system, combining embedded programming, electronic components, sensors, communication modules, motor control, and PC-side software.

## Course Objective

The course introduces students to the challenges of electronic system design and integration through a practical hardware and software co-design project. The Buggy Lab requires coordinated teamwork to design, program, integrate, test, and optimize a complete embedded system.

## Project Stages
### Bronze

The bronze/ directory contains the implementation and sequence information developed for the Bronze stage of the Buggy Lab project.

### Silver

The silver/ directory contains Silver-stage XBee communication code and sequencing, representing the continued development and integration of the buggy communication system.

### Gold

The gold/ directory contains the Gold-stage implementation and supporting development/debugging information, including documentation regarding an observed XBee interface anomaly.

### Ground Station XBee

The gs_xbee_codes.txt file contains code and sequence information associated with the Ground Station XBee interface and its communication with the buggy system.
